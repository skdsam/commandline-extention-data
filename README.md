# Command & Prompt Tracker Data

This repository contains shared commands and prompts for the **Command & Prompt Tracker** VS Code extension.

## How to Subscribe

To import these commands into your own VS Code sidebar:

1.  Open the **Command & Prompt Tracker** sidebar in VS Code.
2.  Expand the **Manage Sources** section at the bottom.
3.  Paste this repository URL: `https://github.com/skdsam/commandline-extention-data`
4.  Click the `+` button.

Your extension will now automatically stay in sync with any updates made to this repository!
